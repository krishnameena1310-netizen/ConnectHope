CONNECTHOPE — FoCP (CSE-1003)
Open index.html in a modern browser. No installation or dependencies required.

FREE HOSTING (GitHub Pages)
Before publishing, confirm you are comfortable making the required name and scholar number public, or ask your teacher about restricted submission alternatives.
1. Create a GitHub repository named connecthope (with appropriate account/guardian permission if required).
2. Upload index.html to the root of the repository and commit it.
3. In repository Settings > Pages, select Deploy from a branch, main, / (root), and Save.
4. Wait for GitHub to display the published URL. Open it in a private browser window and test every feature before submitting.

HOW IT WORKS
HTML structures the site; CSS handles responsive styling. JavaScript uses arrays, objects, functions, conditions, loops, event handlers and browser localStorage. Mood selection is not saved. Journal and checklist data are local to the browser and not encrypted. No accounts, server database, stranger matching or external APIs.

TEST CHECKLIST
Select each mood; change interest and cycle prompts; tick goals and refresh; reset goals; save a sample journal entry and refresh; delete entries; test on a narrow screen. Check name, scholar number and course on homepage. Do not enter private information while testing.

This is an educational prototype, not a medical or counselling service. No live deployment is included in this package.
